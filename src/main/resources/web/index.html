System

Panel Einstellungen

Panel Auftritt

Titel und Logo werden sofort nach dem Speichern im Panel angezeigt. Das Logo sollte per HTTPS erreichbar sein.

Ticket-Arten

Diese Arten werden im Panel und als Tab-Vervollständigung für /ticket create verwendet.

Eine Art pro Zeile oder per Komma getrennt. Sonderzeichen werden automatisch bereinigt.

CloudNet Console

Wenn Basis-URL, Benutzer und Passwort gesetzt sind, nutzt das Panel CloudNet REST mit `/api/v3/node/logLines` und `/api/v3/node/liveConsole` für die aktuelle Live-Konsole.

Der Screen wird nur verwendet, wenn CloudNet REST nicht konfiguriert ist. So bleibt ein Fallback erhalten, falls das Rest-Modul nicht erreichbar ist.

CraftplayQuests Server

Hier hinterlegst du jeden Minecraft-Server, dessen CraftplayQuests-Quests im Browser-Editor gelesen werden sollen. Der Token muss dem `web-editor.token` des jeweiligen Plugins entsprechen.

CraftplayShop Server

Diese Server erscheinen im Serversshop-Tab. Der Token ist für die spätere CraftplayShop Panel-API vorgesehen.

Entbannungsseite

Diese Titel gelten nur für das Entbannungsformular, die Statusseite und die E-Mails, unabhängig vom Panel-Titel.

Entbannungsstatus

Die kurzen Namen werden im Panel, auf der Statusseite und in Status-Mails angezeigt.

Die langen Texte erscheinen als Erklärung auf der Statusseite und in Status-Mails.

Entbannungs-Beweise

Hier legst du fest, wohin hochgeladene Beweisdateien gespeichert werden. Diese Werte werden auch für die klickbaren Beweisdateien im Teampanel genutzt.

Microsoft Anmeldung öffnen

Empfohlen ist die OneDrive-Verbindung über Microsoft-Code. Das URL Template ist optional; ohne Template nutzt das Panel automatisch Microsoft Graph und den OneDrive Ordner.

Panel-Speicher

Die Panel-Speicherart wird beim Start geladen. Wechsel zwischen LOCAL und SQL erfolgt über die CloudNet-Modul-Konfiguration; lokale Daten werden beim SQL-Start automatisch migriert.
